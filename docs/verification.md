# Проверка готовности — 26.10.2026

Реализованы интерфейс, ручной запуск Windows, офисный автозапуск с SSH-туннелем и установщик Ubuntu. Производственные настройки и база при проверке не изменялись. Изменения находятся в рабочем каталоге и не опубликованы в GitHub.

## Автоматические проверки

- `python -B -m unittest discover tests`: 124 теста успешно, включая доступ к настоящим файлам интерфейса через HTTP.
- `node --test tests/test_autosave.cjs`: 4 теста успешно — порядок быстрых изменений, восстановление после 401, сохранение последнего текста при переходе и повтор после частичного сбоя.
- `node --check web/app.js`: синтаксис JavaScript проверен.
- PowerShell Parser: `start.ps1` и `deploy/windows/office-autostart.ps1` без ошибок; файлы сохранены с UTF-8 BOM для Windows PowerShell 5.1.
- `bash -n deploy/install.sh`: синтаксис установщика проверен Git Bash.
- `start.ps1 help` с установленным Python: выбор интерпретатора и передача команды работают.

## Проверка в браузере

На `tests/preview_server.py`, с временной SQLite-базой, вымышленными участниками и отключённым Битрикс24:

1. Вход администратора, раздел участников, создание оценки руководителя с самооценкой и коллегой.
2. Вход участника, выбор оценок и ввод комментария, переход между блоками.
3. Обновление страницы: выбранные оценки и текст комментария на месте.
4. Принудительное истечение тестовой сессии при сохранении: экран входа, повторный вход тем же участником, возврат в анкету и сохранение последнего изменения.
5. Полное заполнение 54 утверждений, открытый комментарий и отправка анкеты; у участника появляется «Оценивать больше некого».
6. У администратора — «заполнили 1 из 2», просмотр отправленной анкеты без возможности редактировать чужие ответы.
7. Скачивание Excel через интерфейс: архив и XML корректны; текст с `<`, `>` и `&` сохранён.
8. Возврат на доработку: статус анкеты изменился; участник снова видит «Продолжить», прежние ответы сохранены и доступны для редактирования.
9. Мобильная ширина 375 px: в анкете и карточке оценки нет горизонтального переполнения; кнопки шкалы 44×44 px.
10. В журнале браузера нет ошибок JavaScript или предупреждений приложения.

## Битрикс24 и размещение

`manage.py check` с существующим вебхуком: успешно получены профиль Натальи и 26 активных пользователей портала.

Создание задач реальным сотрудникам, уведомления и смена статусов реальных задач не выполнялись. Это следующий этап приёмки с выбранным получателем. Установщик Ubuntu и конфигурация Caddy подготовлены, но на VPS не применялись; внешний адрес и автоматический SSH-туннель требуют проверки на целевом сервере. Автоматическое скачивание портативного Python также не выполнялось: запуск проверен с существующим интерпретатором.
